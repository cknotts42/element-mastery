ELEMENT MASTERY — GitHub Pages edition

1. Create a PUBLIC GitHub repository named element-mastery.
2. Upload index.html (plus the optional supporting files icon.svg, manifest.webmanifest, service-worker.js).
3. Open Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
4. Open https://YOUR-USERNAME.github.io/element-mastery/ directly.
5. Add a button/link on your Google Site to that URL rather than embedding it; direct access gives browser storage the best chance of persisting.
6. Complete a two-answer practice item, go Home, reload, and check mastery.
7. Use Export progress backup periodically. Import progress backup restores a saved JSON file.

Progress is per browser/device and does not sync automatically. Browser privacy settings or clearing site data may remove it. Existing Google Sites embed storage does not automatically migrate to the new web origin.
